# Security Policy

## Supported Versions

This repository is maintained as a test suite for the application under test. Security issues affecting the tests themselves should be reported and fixed promptly.

## Reporting a Vulnerability

If you believe you have found a security vulnerability, please do not create a public issue. Instead, report it privately through the repository's preferred secure contact method or the GitHub Security Advisory workflow if enabled.

Please include:

- a description of the issue
- steps to reproduce it
- the affected version or commit hash
- any relevant logs or proof-of-concept details

We will review the report and coordinate a fix and disclosure plan.

## Responsible Disclosure

We appreciate responsible disclosure and ask that reports be kept confidential until a fix is ready.
